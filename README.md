# Nam_Web
This is a look-alike buzzfeed quiz about which character you are in the movie "Howls Moving Castle", enjoy :)

To host the website locally, you need to run the server and the client.

In commandprompt take the path to the server and type: npm run dev

Then in another commandprompt take the path to the client and type: npm run dev

If there trouble opening it on mac it could be due to some issue and this line should work if typed in the project root:
"chmod +x ./node_modules/.bin/nodemon"
This should already be fixed but in case not that is the line.
